# 椿 Live2D 本地模拟资源说明

- 来源压缩包：`E:\Downloads\11月椿.zip`
- 接入用途：MentorFlow 本地、非商用的教师模型模拟与技术验证。
- 原压缩包未被修改；本目录保留作者提供的 `.moc3`、贴图、物理、表情和 VTube Studio 配置。
- `tsubaki.web.model3.json` 是 MentorFlow 额外创建的 Web 装载描述，只登记原包中已经存在的动作与表情，不修改 `.moc3`。
- 原包唯一的 `idle.motion3.json` 实际只驱动眼泪参数；Web 描述将它登记为 `Cry`，避免教师待机时自动哭泣。
- 压缩包只有“使用须知”，没有明确的再发布许可证。若将模型随公开产品分发，必须先取得原作者的明确许可。

原包列出的快捷表情：黑脸、脸红、爱心眼、眼高光消失、哭。
