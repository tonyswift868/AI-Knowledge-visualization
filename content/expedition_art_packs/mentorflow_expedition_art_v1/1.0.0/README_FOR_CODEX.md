# MentorFlow Learning Expedition Art Pack V1

24 张主立绘由 built-in image generation provider 独立生成；其余资源基于各自锁定主立绘制作独立的尺寸/用途版本。

- 每个角色目录包含 11 类资源，每类同时提供 PNG 与 WebP。
- design_hero_id 保留任务要求的固定命名；hero_id 保持当前仓库 HeroDefinition 的运行时 ID，避免改动业务逻辑。
- 图片不包含文字、Logo、UI、水印或外部链接。
- asset_quality_report.json 记录尺寸、透明度、空白比例、SHA-256 和人工复核项。
- 发布前必须人工复核 24 名角色的脸部一致性、表情自然度、透明边缘和技能构图。
