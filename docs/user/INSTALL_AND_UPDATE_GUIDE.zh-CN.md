# 安装与更新 MentorFlow

## 选择安装位置

安装器默认选择当前用户的程序文件夹。需要更换位置时，点击“选择其他位置”，选择一个已经存在的文件夹。

安装器会自动在其中创建 `MentorFlow` 文件夹。例如，选择 `E:\`，会安装到 `E:\MentorFlow`；选择已有的 `E:\Apps`，会安装到 `E:\Apps\MentorFlow`。不需要自己创建空的 MentorFlow 文件夹。

所选文件夹里可以有其他软件。如果安装器提示目标 `MentorFlow` 文件夹中已有不属于本软件的文件，请选择别的位置，不要为继续安装而删除已有文件。

## 检查和更新

打开 MentorFlow，在更新区域点击“检查更新”。未登录时，也可以直接在登录页检查更新。

有新版本时，点击“更新到最新版本”。软件会下载更新、完成更新并自动重新打开，不需要重新下载安装包。

## 软件打不开时

在 Windows 开始菜单中找到“MentorFlow 修复与更新”，打开后按照提示检查、修复或更新。

## 卸载

在 Windows 开始菜单中选择“卸载 MentorFlow”，或在 Windows“设置 → 应用 → 已安装的应用”中找到 MentorFlow，选择卸载。

## 程序与学习资料

程序目录和用户数据目录是分开的。安装位置用于存放软件；学习资料保存在另外的数据目录中。更换安装位置不代表移动学习资料，请不要把数据目录当作程序目录清理。
