## 条目

### [DIR-01] 产品方向：AI 只找资料，不出题、不判主观题
- 状态：已实现（第三十七至七十三批），用户正式测试中。
- 来由：最初设想 AI 自己找资料、出题、判题；实测 AI 不稳定、成本高，出的题和判的分都不可信（用户 2026-10-03、10-06 定）。
- 规则：
  - AI 只负责找资料，以及在资料里“找、指出、配对”（例如指出知识点依据哪一段、问答题要点选哪几条、知识点之间的前置关系）。AI 不出题、不解题、不写答案、不判主观题。
  - 题目只来自资料自带的题，或用户自己上传的题。资料没题的模块只学不考；有题的按题考核（[TEACH-02]、[CHK-01]）。
  - 不用原文挖空出填空题：没有原题的知识点只学不考（用户 2026-10-28 定，取代 2026-10-04 的“没原题就用原文挖空”，[BUG-175]）。已答过的挖空题记录和成绩保留，已通过的模块不撤销。状态：已实现未验证（223-MF06，合入 785a470d），未发布。
  - 老师主动讲课以资料为准，可以打比方、举生活化的例子，也可以补充原文以外的知识，只要不说错、不误导（讲课尺度见 [TEACH-06]，用户 2026-10-14 定）。
  - 学生主动问的问题（用户 2026-10-28 定，[BUG-183]）：老师先在整个计划的资料里找，找到就照资料答并说出处；找不到就用自己的知识直接答，开头标一句“讲义里没有，下面是补充”；这类补充不进考核、不出题。照资料答时可以比资料多说一点点，但说的不能错；常见的一般建议算对（例：“奖项只是佐证之一，不是必需项”），别把老师限制得太死（用户 2026-10-28 定）。状态：已实现未验证（226-MF03 合入 6aeb13e4，228-MF03 第二轮合入 4e49eabf，未发布）；第二轮加了出处检查，真实复测有 2/6 被新检查误拒，已离线修、还没再真实复测，见 [BUG-183]。
  - 用户自己上传的资料、贴的网址和 GitHub 仓库一律当可信资料，照着教，不筛选。
- 关联：[PLAN-06] [TEACH-02] [TEACH-04] [CHK-01]
- 更新：2026-10-10
