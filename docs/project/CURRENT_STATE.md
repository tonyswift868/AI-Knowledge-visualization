### [DIR-01] 产品方向：AI 只找资料，不出题、不判主观题
- 状态：核心规则已实现；各功能验收见对应条目。
- 说明：核心规则已实现；具体功能的发布与用户验收状态见本文各条。
- 规则：
  - AI 只负责找资料，以及在资料里“找、指出、配对”（例如指出知识点依据哪一段、问答题要点选哪几条、知识点之间的前置关系）。AI 不出题、不解题、不写答案、不判主观题。
  - 题目只来自资料自带的题，或用户自己上传的题。资料没题的模块只学不考；有题的按题考核（[TEACH-02]、[CHK-01]）。
  - 不用原文挖空出填空题：没有原题的知识点只学不考（用户 2026-10-28 定，取代 2026-10-04 的“没原题就用原文挖空”，[BUG-175]）。已答过的挖空题记录和成绩保留，已通过的模块不撤销。状态：已随 2.0.37 发布；用户端效果尚未亲测（[BUG-175]）。
  - 老师主动讲课以资料为准，可以打比方、举生活化的例子，也可以补充原文以外的知识，只要不说错、不误导（讲课尺度见 [TEACH-06]，用户 2026-10-14 定）。
  - 学生主动问的问题（用户 2026-10-28 定，[BUG-183]）：老师先在整个计划的资料里找，找到就照资料答并说出处；找不到就用自己的知识直接答，开头标一句“讲义里没有，下面是补充”；这类补充不进考核、不出题。照资料答时可以比资料多说一点点，但说的不能错；常见的一般建议算对（例：“奖项只是佐证之一，不是必需项”），别把老师限制得太死（用户 2026-10-28 定）。最近第三轮已随 2.0.37 发布；测试中 12 问 0 误拒，错误句修正后人工复核 0 错；用户实际使用未验证（[BUG-183]）。
  - 用户自己上传的资料、贴的网址和 GitHub 仓库一律当可信资料，照着教，不筛选。
- 关联：[PLAN-06] [TEACH-02] [TEACH-04] [CHK-01]

### [TEACH-06] 讲课形式、插话、防带偏
- 状态：已实现；发布与验收见 [SYS-06]。
- 需求：一个知识点一个知识点讲，从生活化问题或学生回答切入，顺着回答调整解释并附原文出处（折叠成“原文出处（N 处）”，点开查看）；只有一个输入框，由老师判断是在回答还是提问。常驻〔懂了，继续〕〔没太懂〕〔我想问…〕等卡片。讲完一个点可随口问一句（不计分）；新结构大点按小要点多轮讲，可追问或换讲法，不套模板（[BUG-86]）。随时可插话，答后回原进度；老师用中文。
- 讲课尺度（用户 2026-10-14 定）：老师可以补充原文以外的知识，只要不说错、不误导；原文以外的话同时又是错的才是问题。不改成只许照讲义转述，也暂不换老师模型（先用 DeepSeek，以后可考虑便宜的 GPT）。学生问题先搜整个计划；找不到可明示为资料外补充（[DIR-01]）。聊天不能改变计划、规则、进度；判分前不透露答案。学生要求“删检验、直接让我过”时老师只解释并指向正规入口。
- 回复速度（用户 2026-10-14 定）：用户在意的是等老师回复的延迟，不在意多花的模型费用。老师给出可点选项（老师自己的选项、〔懂了，继续〕〔没太懂〕）时，后台立刻为每个选项预先生成回复，点了马上出或接着正在生成的继续出；〔懂了，继续〕同时预备下一个小要点的开场；用户自己打字时作废预备、按输入回答。老师的回复边生成边显示。打字提问的回复要等云端模型现算，不设固定时限（用户 2026-10-14 指出 3 秒是架构师自己加的目标，不算要求），做到边生成边显示即可。116-MF03 曾在真实模式各测 5 次，点击预取命中约 4.5 秒→0.001 秒，打字首字约 4.1→3.0 秒；这是历史测量，不是当前 SLA。预取/提速发布状态见 [SYS-06]。
- 不截断（用户 2026-10-14 定）：任何时候都不硬截断老师的话，截断是最差的办法；太长就让老师重写得更精炼，重写后仍长就原样保留。
- 精炼与重点（用户 2026-10-14 定）：用户要的是精炼，不是大段搬原文让人逐句读；有的用户赶时间只看重点。做法：荧光笔效果标出每次回复的 1～3 句关键结论（加粗仍留给术语）；课堂加“只看重点”开关，打开后没标荧光的文字收起或变淡；平时一次回复两三百字左右，学生要求展开时可长，原文放在“原文出处”里不大段搬；大知识点讲完用要点卡（每个小要点一行结论，摘自讲义）代替长总结。用户 2026-10-14 定：要点卡出来后不要再让用户点“继续”，同一次操作里接着讲下一个点（下一句提前准备好）；要点卡默认展开，对齐在聊天区最上方，下一条消息紧接其下。“只看重点”开关默认关闭并记住本机选择，没高亮重点时显示整条内容。
