# ADR-002：长课程目录、字幕与分层摘要 v1

- 状态：Accepted
- 日期：2026-08-21
- 适用范围：本地 MentorFlow 中由用户主动提供的 B 站公开视频课程、系列、合集或 BV 视频

## 决策

长课程不再沿用旧的“最多读取前 50 集并拼接全文”路径。v1 以 B 站为正式产品验收目标，使用 yt-dlp 2026.8.19 的 Python API 作为站点适配层，只在用户明确确认后分页读取目录元数据或字幕轨道，并始终启用 `skip_download`。产品层负责工作区隔离、1000 集硬上限、逐集状态、断点、失败原因、证据、覆盖率、摘要树和资料激活。其他站点适配能力属于尽力兼容，不作为 B 站功能通过的替代证据，也不阻塞 B 站交付。

处理分为四个互不冒充的阶段：

1. 目录读取：每页 50 集，接口最多返回 100 集；页面只渲染当前页。
2. 逐集字幕：默认并发 1、硬上限 2；每集独立保存时间戳、来源指纹、失败和重试点。
3. 分层摘要：单集字幕块 → 单集摘要 → 10 集批次 → 递归批次树 → 课程摘要。任何一级都使用有界输入，禁止截断列表尾部或拼接全课程原始字幕。
4. 资料激活：只有用户明确选择“纲领”或“辅助”后，课程级摘要才成为一份资料；它不会自动重建或激活知识地图。

目录与字幕确认不授权模型调用。分层摘要需要第二次独立确认和已验证的真实 Provider；Provider 会话句柄和凭据不写入长课程持久任务。暂停、取消或失败会保留已经完成的逐集证据，应用重启后只标记为可继续，不自动重新发起网络请求。

## 边界与诚实状态

- 最多 1000 集；发现第 1001 集时返回明确限制，不静默截断。
- 单集字幕最多 8 MiB、20,000 段、6 小时；课程最多 256 MiB、2,000,000 段、2,000 小时。
- 只接受 HTTPS、无 URL 用户信息、非本机/私网字面地址的课程及字幕地址。
- ASS/SSA、XML 弹幕和不支持的字幕格式不进入学习证据。
- 覆盖率以用户选中的目录集数为分母；失败、待复核、跳过和未处理分别展示。只要不是全部就绪，界面不得显示“完整课程摘要”。
- 每个摘要都引用已保存的字幕段或下级摘要；课程级摘要可追溯到逐集时间戳。

## 不采用

- 不下载或缓存视频媒体。
- 不把 1000 集标题一次渲染成卡片，也不把全课程字幕拼成一个字符串。
- 不把 yt-dlp 当作课程语义、计划、掌握度或审核引擎。
- 不在未确认或没有真实 Provider 时生成看似完整的摘要兜底。
