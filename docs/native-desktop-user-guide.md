# MentorFlow 原生桌面版：账户与数据库入门

这份说明不要求你有数据库经验。先记住三个结论：

1. 双击 `release\native\MentorFlow.lnk` 即可，软件自己启动和关闭本地服务。
2. 第一次注册时由你设置密码；数据库只保存密码哈希，不保存原密码。
3. 不要手工复制正在运行的 `.db` 文件。需要备份时使用“账户、数据库与调试 → 创建不可变备份”。

## 它为什么不是网页

主窗口、注册登录、任务、资料、知识地图、候选审核、计划、课堂、模型连接和诊断均由
PySide6/Qt 原生控件绘制。业务服务只监听 `127.0.0.1` 的随机端口，由同一个桌面
软件进程管理；它不是需要你另外启动的线上网站。

“完整功能”是迁移期间保留的隔离兼容入口，主要承载尚未重写的 Live2D、远征等旧
工具。即使某个旧工具暂时没有原生替代，也不会为了重写而删除已有功能和进度。

## 第一次注册发生了什么

第一次启动会显示注册窗口：

- 用户名是以后登录时输入的短名称。
- 显示名称只是界面称呼。
- 密码至少按界面要求设置；软件用 Argon2id 生成带随机盐的密码哈希。
- 第一个账户会认领升级前已经存在的任务。认领只是新增归属记录，不改写计划、材料或进度。

同一台电脑可以继续创建其他本地账户。后续账户从空白空间开始，且只看到自己创建的
资料、地图、计划、课堂和进度；老账户重新登录后仍恢复自己的原记录。用户名不区分
大小写，两个注册请求即使同时提交，同一用户名也只能成功一个。

把 `release\distributable\MentorFlow` 整个目录复制给另一位 Windows 用户即可运行；
不能只单独复制其中的 EXE。发布目录不含你的账号、数据库、资料或 Provider Key。
对方首次启动会在 `%LOCALAPPDATA%\MentorFlow` 建立自己的空白数据库并注册首个账户。

## 两个数据库分别是什么

- `data\mentorflow_v2.db`：当前主数据库。账户、登录会话、任务归属、主动教学、
  知识地图修订、规范计划和执行进度都在这里。
- `data\app.db`：旧功能仍会读取的兼容数据库。它暂不与主库按名称或正文自动合并。

注册登录新增的三张表：

- `orm_local_users`：用户名、显示名称、Argon2id 密码哈希。
- `orm_local_sessions`：登录令牌的 SHA-256 哈希、有效期、撤销时间。
- `orm_workspace_ownership`：哪个本地账户拥有哪个任务。

原始密码和原始会话令牌都不在这些表里。Provider API Key 更不会进入 SQLite；它由
Windows Credential Locker 保存，数据库和 Qt 设置只接触 `mfcred_...` 引用。

## 日常使用顺序

1. 在“资料管理”新建任务并选择文件。解析失败会明确显示原因。
2. 在“学习计划”填写目标、开始/截止日期、学习星期和容量，勾选纳入资料并保存。
3. 在“模型连接”确认真实 Provider 已验证。
4. 在“知识地图”点击“从资料生成”，等待任务进入 `ready` 或 `ready_with_review`。
5. 查看节点、关系和证据；逐项确认或驳回待审核候选。
6. 回到“学习计划”生成预览。顺延和未纳入资料都必须显式确认，系统不会偷偷激活。
7. 在“原生课堂”进入学习，阅读教师讲解、提交回答或附件。手动跳过会记录
   `manual_skip`，不算掌握。

## 备份和恢复

点击“创建不可变备份”会：

- 使用 SQLite 在线备份 API 复制两个数据库，而不是直接抢拷正在写入的文件；
- 保存上传资料和运行配置；
- 对备份数据库运行 `PRAGMA integrity_check` 并记录每张表行数；
- 为每个文件写 SHA-256 清单；
- 把备份文件设为只读，并生成 `RESTORE.txt`；
- 明确排除密钥文件，不读取其内容。

恢复属于覆盖现有数据的高风险操作，所以软件不会在运行中提供“一键恢复”。正确步骤：

1. 退出 MentorFlow。
2. 先给当时的数据再创建一份独立备份。
3. 核对目标备份的 `manifest-sha256.json` 和 `sqlite-integrity-and-row-counts.json`。
4. 按 `RESTORE.txt` 把相对路径复制回项目相同位置。
5. 再次检查 SHA-256 和 SQLite 完整性后启动软件。

如果你不确定，不要直接覆盖文件；把“复制诊断信息”的结果和备份目录发给开发者即可。

## 如何和开发者一起调试

- 日常入口：`release\native\MentorFlow.lnk`，不显示控制台。
- 调试入口：`release\native\MentorFlow-Debug.lnk`，显示本地运行日志。
- “复制诊断信息”只复制版本、表数量、行数和完整性，不包含密码、API Key 或材料正文。
- 修改当前源码后重新启动软件即可验证；开发版入口始终指向当前工作树和当前数据。
