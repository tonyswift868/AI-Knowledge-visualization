| 测试 | 操作与预期 |
| --- | --- |
| A 管理员 | 用 tonyswift555 及已知测试密码登录；服务器角色为 SUPER_ADMIN；进入学习空间。 |
| B 注册 | 注册新账号 → 邮箱收到验证信 → 浏览器点击验证 → 回到原生登录 → 普通账号为 LEARNER。 |
| C 忘记密码 | 填写账号 → 收到重置邮件 → 新密码与确认密码一致 → 重置成功 → 旧密码失败、新密码成功。确认密码始终隐藏；两次不一致不可提交；重置不会自动登录。 |
| D 多账号 | 添加两个账号，分别进入学习空间，再切换；账号、会话、凭据和本地资料互不混用。 |
| E 记住密码 | 勾选“记住密码”，登录后关闭、重开；点击登录可使用 Windows 凭据管理器安全保存的凭据。都不勾选时不保存密码。 |
| F 自动登录 | 开启“自动登录”，登录后关闭、重开；进入正确账号。优先恢复会话，只有明确保存过密码才允许凭据回退。 |
