# 本地认证恢复说明（历史兼容）

本地认证和手机号恢复功能已经退休。当前桌面版是单用户模式，不提供账号创建、登录、
密码修改、短信绑定、密码找回或远程认证入口；也没有可执行的启用步骤。

历史数据库仍可能包含以下迁移创建的表和行：

- `0018_local_user_authentication`：本地用户、会话和工作区归属；
- `0020_local_phone_recovery`：手机号字段和挑战记录；
- `0021_local_login_throttle`：旧登录失败计数和锁定字段。

这些表只为旧数据库读取、备份和迁移兼容而保留。运行时不会查询它们来决定访问，也不会
删除、重建、清空或改写既有用户数据。若需要迁移数据，请使用数据库备份/导入流程并先
停止桌面程序；不要手工删除这些表。
