# MentorFlow 云端边界（历史兼容说明）

MentorFlow 当前产品原则是本地单用户。桌面程序只启动绑定
`127.0.0.1` 的本地 API，数据、上传资料和 Provider 会话句柄留在本机；账号、登录、
注册、短信恢复和远程多租户 API 均已退休。不要按旧文档把本地安装包接到公网账户服务。

## 历史数据库兼容

迁移 `0018_local_user_authentication`、`0020_local_phone_recovery` 和
`0021_local_login_throttle` 及其表会继续保留，用于读取旧数据库和保留既有行。它们不再
由运行时代码创建账户、认证请求或隔离工作区；不要删除表、回滚迁移或清理历史数据。

## 数据移动与备份

需要把数据带到另一台电脑时，使用桌面端的数据库备份/导入流程，并在停机状态下核对
SQLite 完整性和文件清单。备份中不应包含 Provider 密钥；Provider 只保存本地凭据引用。

如果未来重新设计远程产品，必须单独定义服务端身份、租户授权、HTTPS、审计和备份策略，
不能通过恢复已退休的本地账号路由实现。
