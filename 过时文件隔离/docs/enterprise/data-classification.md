# MentorFlow Enterprise data classification

Status: **PARTIAL**. Classes are `PUBLIC`, `INTERNAL`, `CONFIDENTIAL`, and `RESTRICTED`. Encryption/retention entries are required seams; absent owner proof remains `PENDING_OWNER_EVIDENCE`.

| Data | Class | Encryption | Logging policy | Export policy | Retention seam | Evidence / owner |
|---|---|---|---|---|---|---|
| Approved public documentation and frontend assets | PUBLIC | transport integrity/TLS for delivery | access logs may record path/status, never secrets | public release only from reviewed exact commit | retain per release policy | CI_CONFIGURED / 07-release |
| Email and account metadata | CONFIDENTIAL | TLS in transit; database encryption-at-rest seam | redact full email where not operationally required; no auth token | user/admin authorized export only | account lifecycle and deletion policy required | PENDING_OWNER_EVIDENCE / 04-identity |
| Organization membership and role bindings | CONFIDENTIAL | TLS + database encryption-at-rest seam | audit changes by subject/resource/action; no raw token | tenant-admin/legal export only | membership end/role history policy required | PENDING_OWNER_EVIDENCE / 02+04 |
| Uploaded documents and derived Evidence | RESTRICTED | TLS; encrypted object storage/volume seam; encrypted backup | never log content; log identifiers, size, disposition, status | same-tenant authorized export with audit | disposition, deletion, and legal-hold seam required | document policy PARTIAL; storage evidence PENDING_OWNER_EVIDENCE / 05 |
| Student Model | RESTRICTED | TLS + database encryption-at-rest seam | no raw model snapshot in logs/traces | learner/authorized tenant export only | learning-history retention/deletion seam required | PENDING_OWNER_EVIDENCE / learning owner |
| Misconceptions and assessment inferences | RESTRICTED | same as Student Model | log only aggregate/error metadata | bundled only with authorized learner export | correction and deletion workflow required | PENDING_OWNER_EVIDENCE / learning owner |
| Review history and Review Memory | CONFIDENTIAL | TLS + database encryption-at-rest seam | identifiers and state transition only, no private content | same learner/tenant scope only | schedule/history retention seam required | local module tests; tenancy evidence pending / review owner |
| Provider credentials, release tokens, JWTs, private keys | RESTRICTED | secret manager; encrypted transport; never persisted in artifacts | never log; mandatory redaction and secret scan | export prohibited except controlled rotation/recovery | rotate/revoke/destroy by secret lifecycle | CI_CONFIGURED; vault lifecycle PENDING_OWNER_EVIDENCE / 06+platform |
| Audit metadata and immutable Evidence receipts | INTERNAL, elevated to CONFIDENTIAL when tenant-linked | TLS + integrity-protected storage | audit stream is the record; exclude payloads/secrets | security/compliance export with scope and chain of custody | retention/immutability policy required | PENDING_OWNER_EVIDENCE / 03 |
| Cost events, budgets, and provider usage ledger | CONFIDENTIAL | TLS + database encryption-at-rest seam | no credentials/prompts; tenant/account IDs minimized | authorized finance/admin scope only | billing/audit reconciliation retention seam | PENDING_OWNER_EVIDENCE / 06 |
| Logs and traces | INTERNAL by default; CONFIDENTIAL if tenant-linked | TLS exporter + encrypted backend seam | allowlisted fields; redact auth, secrets, raw docs/prompts | incident/compliance export only | sampled operational retention + deletion policy | PENDING_OWNER_EVIDENCE / 03 |
| Database, object-storage, and configuration backups | RESTRICTED | encrypted before/at storage; key separate from backup | log checksum/job/result, never backup contents or keys | controlled restore only; no ad-hoc download | tested expiry, legal hold, and secure deletion seam | `STAGING_EXECUTION_PENDING` / 03+platform |
| SBOM, dependency findings, release manifests | INTERNAL | integrity/provenance; confidential registry auth excluded | safe to log identifiers/status, not tokens | release/security reviewers | retain with immutable release evidence | IMPLEMENTED/CI_CONFIGURED / 07 |

No row claims production encryption, export, or retention execution unless a retained owner/staging artifact is named. Fixtures, build artifacts, source, config, and logs remain in secret-scan scope.
