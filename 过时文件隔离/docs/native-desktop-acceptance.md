# MentorFlow 原生桌面版验收边界

## 当前交付边界

- Windows GUI 启动器负责启动、健康检查和关闭仅监听随机 loopback 端口的 FastAPI 服务；
- 主窗口、任务、资料、知识地图、计划、课堂、Provider 连接、数据库诊断和备份由 Qt 原生控件提供；
- Live2D、远征等尚未迁移的功能继续通过隔离兼容页提供；
- 产品是本地单用户，账号/远程认证和手机号恢复不属于交付功能。

## 验收要求

- 本地服务健康检查返回 `status=ok`；
- 主窗口可以构造并显示；
- `/api/workspaces` 可读取并显示当前数据根目录中的工作区；
- 新建的本地工作区能在列表中再次读取；
- 备份数据库通过 SQLite 完整性和文件清单核对；
- OpenAPI 不包含 `/api/auth/*` 路由，桌面冒烟不设置旧认证环境变量、不调用旧路由；
- 删除账号实现不会影响迁移 `0018`、`0020`、`0021` 的表或既有数据行。

## 诚实限制

原生课堂仍可导入录音文件并调用本地 ASR；实时麦克风录制尚未原生化。发布版启动器仍
面向持续调试和当前源码验证，不应描述为脱离项目目录的冻结安装包。
