# MentorFlow 原生桌面版：本地单用户指南

双击 `release\\native\\MentorFlow.lnk` 即可启动。桌面程序会自行启动本地服务、打开主窗口，
并在退出时关闭服务；不需要额外启动网站或配置远程身份。

## 数据目录

- `data\\mentorflow_v2.db`：当前 ORM 数据库，保存任务、资料、计划、课堂和 Provider 会话元数据；
- `data\\app.db`：旧功能读取的兼容数据库；
- 上传目录：由本地数据根目录下的运行配置决定。

本地模式不会按账户筛选工作区。已有旧数据会继续显示，新建任务直接写入当前本地数据根目录。
Provider API Key 只写入 Windows Credential Locker，数据库和 Qt 设置只保存 `mfcred_...` 引用。

## 历史认证表

迁移 `0018_local_user_authentication`、`0020_local_phone_recovery`、`0021_local_login_throttle`
创建的用户、会话、手机号、锁定和归属表仍会随数据库保留。它们是历史兼容结构，不是当前
运行时身份边界；不要删除、清空或回滚这些表，也不要据此推断当前桌面仍支持远程认证。

## 日常顺序

1. 在“资料管理”创建任务并导入资料。
2. 在“学习计划”填写目标、日期和学习容量，确认后生成计划。
3. 在“模型连接”验证 Provider（真实密钥只经凭据引用读取）。
4. 在“知识地图”检查节点、关系和证据，再处理待审核候选。
5. 在“原生课堂”学习并提交回答、附件或录音文件。

## 备份和恢复

通过“数据库与调试”创建备份。程序使用 SQLite 在线备份 API、完整性检查、行数报告和
SHA-256 清单；备份排除密钥文件。恢复前退出 MentorFlow，先保留一份当前备份，再按
`RESTORE.txt` 复制并重新核对清单。
