# MentorFlow

MentorFlow 将资料、证据、知识地图、计划、AI 教学、评估和复习逐步连成学习流程。目前从账号外壳开始渐进重构，具体范围与实际进度只维护在以下两份对接文档：

- [项目细节](docs/project/CURRENT_STATE.md)：产品、模块状态、架构、接口、运行位置、服务器和验证证据。
- [员工调度](docs/project/WORKFLOW.md)：架构师内部的调度记录；员工执行直接任务消息，不读取或监控该板。

**当前开发与重构入口：[refactor](refactor/)。** 用户启动入口：[Start-MentorFlow.cmd](Start-MentorFlow.cmd)。旧源码、共用运行材料和历史资料的分区见[项目细节](docs/project/CURRENT_STATE.md#3-当前代码边界与接口)。
